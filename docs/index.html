Pollinations API Adapter Starter

A minimal Node.js starter showing server-side Pollinations chat completions, Pollen balance checks, quota handling, and a compact metadata translation workflow.

View Source Pollinations

OpenAI-Compatible

Uses /v1/chat/completions with a small dependency-free client.

Quota Aware

Handles HTTP 402 responses and parses nextResetAt from the profile endpoint.

Server-Side Keys

Keeps POLLINATIONS_API_KEY in server environments and out of browser bundles.

const client = createPollinationsClient({
  apiKey: process.env.POLLINATIONS_API_KEY,
});

const text = await client.chatText({
  messages: [{ role: "user", content: "Write a short intro." }],
});
